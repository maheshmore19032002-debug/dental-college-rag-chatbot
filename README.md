
# Dental College RAG Chatbot

A multilingual Retrieval-Augmented Generation (RAG) chatbot
for answering questions using official dental college website
pages and PDF documents.

## Project Goals

- Retrieve relevant information from official sources.
- Answer questions in English, Marathi, and Hindi.
- Provide source-grounded answers.
- Reduce unsupported or fabricated responses.
- Develop and evaluate the system locally before deployment.

## Planned Technology

- Python
- Google Gemini API for answer generation (free-tier access, subject to availability)
- Multilingual sentence embeddings
- FAISS vector search
- FastAPI for the future backend
